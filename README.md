# KAIZ — Installer

**Smarter work, greater impact.** Kantor AI di laptop Anda yang mengubah video & foto mentah menjadi konten vertikal siap upload.

## Unduh
👉 **[KAIZ-Setup.exe versi terbaru](https://github.com/huseinzk/KAIZ-AI-releases/releases/latest)** (Windows 10/11, 64-bit)

1. Jalankan `KAIZ-Setup.exe` (tidak perlu admin).
2. Bila muncul *"Windows protected your PC"*: klik **More info → Run anyway**.
3. Buka KAIZ dari Start Menu / Desktop.

## Pembaruan
KAIZ mengecek repo ini secara otomatis. Saat ada versi baru, klik **Perbarui sekarang** di aplikasi — installer diunduh lewat HTTPS, diperiksa sidik digitalnya (SHA-256), lalu dipasang otomatis. Pengaturan & riwayat Anda tetap aman.

Repo ini hanya berisi installer. Kode sumber bersifat privat.
